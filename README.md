# CloudVPS Game Responsive

Trang landing page HTML/CSS/JS bán VPS + Proxy chuyên cho game mobile.

## Có sẵn
- Responsive desktop / laptop / tablet / mobile
- Header sticky + menu hamburger
- Hero VPS Game + Proxy Game
- Khu NinjaSchool / Ngọc Rồng Online / game mobile khác
- Tab bảng giá VPS / Proxy
- Đổi giá tháng / năm
- Tính năng game: Low Ping, Anti-DDoS, open port
- Dashboard quản lý
- FAQ
- CTA + Footer

## Cách chạy
Mở `index.html` bằng Chrome/Edge hoặc upload cả 3 file:
- index.html
- style.css
- script.js

vào `public_html`.

## Nên chỉnh tiếp
- Đổi thương hiệu CloudVPS
- Thay giá thật
- Gắn nút Thuê ngay/Mua ngay sang trang thanh toán
- Thay hotline/email thật
- Kết nối backend/API cấp VPS/Proxy nếu có
